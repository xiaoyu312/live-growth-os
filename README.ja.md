# Live Growth OS

**ライブ配信の指標、文字起こし、商品情報をひとつにまとめ、根拠と有効期間を添えて運営上の提案を確認できます。**

Live Growth OS は、ライブ配信の運営チームと開発者向けのローカルワークスペースです。入力された指標、文字起こし、商品情報を、ルールと状態機械が時間窓や欠損データの状態と合わせて処理し、人が確認するための提案を生成します。まずはリポジトリ内の合成シナリオで流れを確認できます。

このソース版には、既存の **Next.js Web アプリ、Fastify サーバー、Chrome 拡張機能、Electron デスクトップアプリ、共有の契約／ルールモジュール** が含まれます。内部の実配信データの再生と専用評価フローは明示的に無効化されています。業務記録、元のトーク原稿・文字起こし、アカウントの事前設定、インストーラーは含みません。現状は**実験的な公開ソース版**です。ソース整理時に静的な参照先の整合性確認と限定的なオフラインチェックを完了しましたが、クリーンインストール、完全な意味解析を伴う型チェック、全テスト、ビルド、起動の検証は未完了です。

## 既存の合成シナリオを確認する

リポジトリには[シナリオデータ](examples/synthetic-scenarios.json)と[生成スクリプト](scripts/generate-synthetic-demo.mjs)があります。以下は既存 JSON からの抜粋で、データの由来を示す分類と固定シードです。実際の運営成果ではありません。

```json
{
  "classification": "independently_synthetic",
  "seed": 20300101,
  "startAt": "2030-01-01T00:00:00.000Z"
}
```

シナリオ内の `sampleSize: 0` は、過去の観測データを使っていないことを示します。生成スクリプトは固定値とシードだけを使い、外部ファイルの読み取りやネットワーク通信を行いません。`examples/synthetic-scenarios.json` と `packages/source-adapters/src/calibrations/historical.ts` を再生成します。旧来のエクスポート名はソース互換性のためだけに残しています。価格や GMV の例は独立に選んだ架空の切りのよい数値で、実際の注文を匿名化したものではありません。[合成例の由来（英語）](examples/README.md)も参照してください。

## 最短の使い方：ローカル合成デモ

Node.js 24+ と pnpm 10.33.0 が必要です。リポジトリのルートから次のコマンドを実行します。以下は利用手順であり、**今回の文書整理では依存関係のインストールもアプリの起動も行っていません**。

```sh
pnpm install --frozen-lockfile
pnpm demo:generate
pnpm dev
```

フロントエンドの既定アドレスは `http://127.0.0.1:3000`、サーバーは `http://127.0.0.1:4100` です。`dev` は明示的にメモリストレージを使います。`http://127.0.0.1:3000/lab` または `/mvp` を開き、合成シナリオを選んで開始します。更新や終了後のメモリデータの保持は保証しません。旧実配信の選択肢は自動読み込みされず、対応する旧 API は内部データが含まれていないことを返します。合成記録を実配信の記録として表示することはありません。

## 含まれる機能

- Next.js ワークスペース：配信状態、データソースの稼働状況、運営ルール、合成シナリオ、商品設定、振り返り画面。
- Fastify サーバー：イベントの検証と重複排除、メモリ上のデモ、PostgreSQL 永続化インターフェース。デスクトップ版は SQLite を使用。
- 決定的なルール、状態機械、時間窓集計、欠損値と根拠の判定、人による確認、復旧処理の頻度制限。
- Chrome 拡張機能：利用者が明示的に接続した、利用権限のある罗盘／千川ページでの指標収集と任意の音声処理。
- Electron の起動、子プロセスの分離、ナビゲーション制限、ソースからのパッケージング用スクリプト。ビルド済みバイナリは非同梱。
- 公式 API、ASR、LLM、ワークブックの履歴インポート用の設定可能なアダプター。未設定のサービスには自動でリクエストしません。

過去の業務ルールの係数と元のトーク原稿は一括で除外しています。公開版のルール初期値と旧時間帯プロファイルの互換エクスポートは独立した合成値であり、過去の統計、業界の基準、有効性が確認された運営戦略ではありません。元の分析アルゴリズムは保持しており、`analyzeRules` に呼び出し側のルール設定を渡せます。参考スクリプトは汎用的な合成の要点で、分野固有の ASR 語彙は既定で空です。

## 外部接続とデスクトップ版

実データを収集するには、利用者自身がアクセス権限を持つプラットフォームのページに明示的に接続する必要があります。拡張機能は許可後に実際の指標や任意の音声を処理するため、**常にオフラインで動くツールではありません**。千川の公式認証、ASR、LLM、ワークブック履歴の同期には、利用者自身の設定と権限が必要です。認証情報やアカウント認可は同梱せず、広告アカウントの操作や提案内容の実行を自動で行いません。

`.env.example` の連携設定値は空です。メモリデモではコピーする必要はありません。永続化にはデータベースと Redis を自分で設定した後、`pnpm db:migrate` を実行します。環境設定ファイル、録音、実行データのディレクトリを Git にコミットしないでください。履歴インポートには `HISTORY_REGISTER_URL` の明示的な設定と、別途インストールした `lark-cli` を `PATH` に追加することが必要です。自分のアカウントと対象ワークブックへの認証・認可も利用者が行います。この CLI は同梱していません。毎日の同期には `HISTORY_DAILY_SYNC=1` も明示的に有効にします。

拡張機能は `pnpm --filter @live-growth/extension build` でビルドし、ブラウザのデベロッパーモードで `dist` を読み込みます。デスクトップ版は `pnpm desktop:build` でビルドし、`pnpm --filter @live-growth/desktop start` で起動します。`desktop:pack:mac` / `desktop:pack:win` はパッケージングの入口です。動作、署名、インストール、プラットフォームへの接続は未検証です。インストーラーを配布する前に、同梱依存関係のライセンス表記も確認してください。

## 検証と成熟度

既存のチェックコマンドは次のとおりです。今回は文書のみを確認しており、アプリのテストやビルドは実行していません。

```sh
pnpm check:public
node --test apps/desktop/tests/*.test.cjs
pnpm typecheck
pnpm test
pnpm build
```

ソース整理時に、最初の 2 項目は隔離された候補版で実行済みです。残りの 3 項目は完全な依存関係が必要で、その時点では実行していません。内部しきい値を独立した公開用の例に置き換えたため、元のシナリオ発火テストは特に再検証が必要です。

既存の記録では、13 件の独立したオフライン動作／デスクトップのモックテスト、176 個の TypeScript ファイルの構文と静的な相対参照先の確認、拡張機能のマニフェストチェックが完了しています。完全な意味解析を伴う型チェック、元の Vitest テスト一式、クリーンインストール／ビルド／起動、ブラウザ表示、実プラットフォームへのリクエスト、デスクトップのパッケージング、業務上の成果は未検証です。静的スキャンだけで未知の機密値が一切残っていないと保証することはできません。
